## How to update on Render (GitHub)

1. Open your GitHub repository
2. Click `app.py` → pencil icon (Edit)
3. Select all (Ctrl+A) → Delete
4. Paste the entire new `app.py`
5. Commit changes (message: "PhD-level + Biology + 6-step trajectories")
6. Render auto-deploys (or Manual Deploy → Deploy latest commit)
7. Wait until status is Live
